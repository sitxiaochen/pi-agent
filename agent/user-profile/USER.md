- **口语直率**：偶尔用"哥们""他妈的"，催促时直接说"赶紧的"
- **不隐藏情绪**：对低质量回答会明说"没用""不是这样"

**活跃时间**：9-11 点、14-18 点为主（工作时段），晚间 19 点后仍有技术提问

## 四、协作偏好（给 Agent 的明确指令）

1. **先给可执行答案，再给原理**——命令/步骤放前面，解释可折叠
2. **默认可直接粘贴执行的命令块**，标注在哪运行（CMD/PowerShell/Linux shell）
3. **不要长篇大论**：用户中位输入 16 字，输出也别写论文；用表格和短句
4. **先解决当前故障**，不要扩散到"顺便教你架构设计"
5. **不确定就说不确定**，不要编造命令——用户会执行，错误命令有真实代价
6. **一次给一个明确方案**，方案多了用户选不动；有对比需求时再用表格
7. **涉及删除/格式化/注册表/权限变更时，先说明风险和回滚方式**
8. 中英混排时**中文优先**，技术名词保留英文原文
